# Week 10 - LangChain Basics

## Project Description
This project demonstrates chatbot development using LangChain and the Ollama Llama 3.2 model.

## Activities
1. Model Initialization
2. Prompt Templates
3. Testing 20 User Queries
4. Prompt Comparison
5. Text Summarization Chain
6. Question Answering Chain
7. Week 9 vs Week 10 Comparison

## Features
- College Assistant Chatbot
- Multiple Prompt Templates
- User Query Testing
- Prompt Comparison
- Text Summarization
- Question Answering
- CSV Response Logging

## Technologies Used
- Python
- LangChain
- Ollama
- Llama 3.2
- Pandas
- Jupyter Notebook

## How to Run
1. Install Ollama.
2. Download the Llama 3.2 model using `ollama pull llama3.2`.
3. Install the required packages using `pip install -r requirements.txt`.
4. Run the chatbot using `python langchain_chatbot.py`.

## Project Structure
- `dataset/` - Input and output CSV files
- `notebook/` - Jupyter Notebook
- `langchain_chatbot.py` - Main chatbot program
- `requirements.txt` - Required Python packages
- `.gitignore` - Files excluded from GitHub
